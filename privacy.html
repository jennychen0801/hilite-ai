HiLite AI 隱私權政策

最後更新：2026-10-21

1. 收集的資料

HiLite AI 不設伺服器，開發者不會收集、接收或儲存任何使用者資料。

2. 本機資料

畫線、筆記、標籤、AI 摘要、對話紀錄和設定（包括使用者自行輸入的 AI API Key），都存在使用者瀏覽器的本機儲存空間。

3. Google 帳號與 Google Drive

  • 使用者主動啟用雲端同步時，擴充功能會要求 openid、email 和 https://www.googleapis.com/auth/drive.appdata 權限。
  • email 只用來在設定頁顯示目前登入的帳號。
  • drive.appdata 只用來在使用者自己的 Google Drive「應用程式資料」隱藏資料夾讀寫本擴充功能建立的同步檔案，無法存取使用者 Drive 裡的其他檔案。
  • API Key 不會上傳到 Google Drive。
  • 使用者可以隨時在設定頁登出、刪除雲端資料，也可以到 Google 帳戶權限頁面 撤銷授權。

4. AI 服務

使用者執行摘要或對話時，網頁內容和提問會直接從瀏覽器送到使用者自己設定的 Azure OpenAI 或 Google Gemini 服務，適用該服務的條款，不會經過開發者。

5. 分享

不會把任何使用者資料出售或分享給第三方。

6. Google API 服務使用者資料政策

HiLite AI 使用從 Google API 取得的資訊時，會遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

Privacy Policy (English)

HiLite AI has no server. The developer does not collect, receive, or store any user data. Highlights, notes, summaries, chats, and settings (including the user's own AI API keys) are stored locally in the browser. When the user enables cloud sync, the extension requests openid, email, and drive.appdata solely to store sync files in the hidden application data folder of the user's own Google Drive; it cannot access other Drive files, and API keys are never uploaded. AI requests go directly from the browser to the AI service configured by the user. No data is sold or shared. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time at Google Account permissions.
