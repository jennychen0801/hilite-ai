HiLite AI

HiLite AI 是一個個人用的 Chrome / Edge 擴充功能，可以在網頁上畫線、寫筆記，並用使用者自己的 Azure OpenAI 或 Google Gemini 金鑰做摘要和對話。

HiLite AI is a personal Chrome / Edge extension for highlighting web pages, taking notes, and summarizing content with the user's own Azure OpenAI or Google Gemini API key.

Google 帳號的用途 / Use of Google account

登入 Google 只用來把使用者自己的畫線與筆記同步到該使用者 Google Drive 的「應用程式資料」隱藏資料夾（drive.appdata），讓同一個人在不同電腦之間同步。開發者不會收到、儲存或讀取任何使用者資料。

Google sign-in is used only to sync the user's own highlights and notes to the hidden application data folder in that user's Google Drive (drive.appdata). The developer does not receive, store, or access any user data.
